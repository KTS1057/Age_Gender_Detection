# 🎯 Age & Gender Detection 

## 📌 Project Description

Age & Gender Detection is a deep learning-based web application that predicts the approximate age group and gender of a person from an uploaded facial image.

The project uses a trained TensorFlow/Keras deep learning model and provides an easy-to-use interface through Streamlit.

Users can upload an image, and the application processes the image and displays the predicted gender along with the model's probability scores.

## ✨ Features

- 📷 Upload a facial image
- 🧠 Deep learning-based prediction
- 👤 Gender classification
- 📊 Male and Female probability scores
- ⚡ Fast prediction
- 🌐 Interactive Streamlit web interface
- 💻 Simple and user-friendly interface
- 🚀 Deployed online using Streamlit Community Cloud

## 🧠 Machine Learning Model

The application uses a trained TensorFlow/Keras deep learning model for facial image analysis.

The trained model is stored in the `models/` directory and is loaded by the prediction module during application execution.

The model performs gender classification and returns probability scores for the predicted classes.
